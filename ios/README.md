# Приложение «БНО» для iOS

Нативная оболочка (SwiftUI + WKWebView) для сайта архива. Адрес сервера задаётся в самом приложении: домен (`archive.example.ru`) или IP с портом (`192.168.1.10:8000`).

Что умеет:

- экран подключения с проверкой связи и списком недавних серверов;
- нижняя панель «назад / вперёд / главная / обновить / настройки», свайпы назад-вперёд, обновление жестом «потянуть вниз»;
- ссылки на сторонние сайты открываются в Safari;
- диалоги сайта (`confirm`, `prompt`) показываются как системные окна, поэтому редактор в админке работает полностью;
- экран «связь потеряна» при недоступном сервере;
- «выйти и очистить данные» в настройках.

Сайт узнаёт приложение по метке `BNOApp/…` в User-Agent: у `<html>` появляется атрибут `data-app`.

## Сборка без Mac

Сборку делает GitHub Actions (`.github/workflows/ios.yml`) при каждом изменении в папке `ios/`. Запустить её вручную: GitHub → Actions → «iOS-приложение» → Run workflow.

1. Дождитесь зелёной галочки и скачайте артефакт **BNO-ios**. Внутри лежит `BNO.ipa`.
2. Установите [Sideloadly](https://sideloadly.io) на Windows и подключите iPhone кабелем.
3. Перетащите `BNO.ipa` в Sideloadly, введите свой Apple ID и нажмите Start.
4. На iPhone откройте «Настройки → Основные → VPN и управление устройством» и доверьте своему Apple ID.

С бесплатным Apple ID приложение работает 7 дней, потом Sideloadly переустанавливает его в один клик. С платным аккаунтом разработчика (99 $ в год) — год. Через него же можно выложить приложение в TestFlight или App Store.

## Сборка на Mac

```bash
brew install xcodegen
cd ios
xcodegen generate
open BNO.xcodeproj
```

В Xcode выберите свою команду в Signing & Capabilities и запустите приложение на телефоне.

Идентификатор пакета — `ru.bno.archive`, меняется в `project.yml`.
